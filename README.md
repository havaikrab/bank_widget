# Bank Widget

## Описание:
Bank Widget - это проект, созданный и постепенно дорабатываемый в рамках обучения языку программирования Python.

## Цель проекта:
Главной целью Bank Widget является получение и совершенствование навыков по работе с локаоьным и удаленным репозиторием Git.

## Установка:
1. Запустите IDE на локальном ПК.


2. Клонируйте Bank Widget из удаленного репозитория.

    Для этого можно из текущей директории на вашем ПК можно ввести в терминале команду: git clone git@github.com:havaikrab/bank_widget.git


3. Установите зависимости.

    В проекте используется менеджер зависимостей Poetry, установите его, при необходимости.
    Для установки зависимостей введите в терминале команду: poetry install

## Инструкции и комментарии к функциям:

### get_mask_card_number()

Функция принимает на вход строку с номером карты и возвращает ее маску.  
Номер карты замаскирован и отображается в формате  
XXXX XX** **** XXXX,  
где X — это цифра номера.  

#### Пример работы функции:  

Входные данные: 7000792289606361  
Результат:      7000 79** **** 6361  

### get_mask_account()

Функция принимает на вход строку с номером счета и возвращает ее маску.  
Номер счета замаскирован и отображается в формате  
**XXXX  
где X — это цифра номера.  

#### Пример работы функции:  

Входные данные: 73654108430135874305  
Результат:      **4305

### mask_account_card()

Функция принимает один аргумент — строку, содержащую тип и номер карты или счета,
и возвращает строку с замаскированным номером.  
Для маскировки номеров карт и счетов используются соответствующие функции get_mask_card_number() и get_mask_account()  

#### Примеры работы функции:  

Входные данные: Visa Platinum 7000792289606361  
Результат:      Visa Platinum 7000 79** **** 6361  

Входные данные: Счет 73654108430135874305  
Результат:      Счет **4305

### get_date

Функция принимает на вход строку с датой в формате:  
"2024-03-11T02:26:18.671407"  
и возвращает строку с датой в формате "ДД.ММ.ГГГГ"  
"11.03.2024".

### filter_by_state()

Функция принимает список словарей и, опционально, значение для ключа state,  
по умолчанию state = 'EXECUTED'.  
Функция возвращает новый список словарей с соответствующим значением ключа state

### sort_by_date()

Функция принимает список словарей и опциональный параметр, задающий порядок сортировки,  
по умолчанию сортировка происходит по убыванию.  
Функция возвращает новый список, отсортированный по дате, то есть по значению ключа "date".
