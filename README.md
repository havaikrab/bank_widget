# Bank Widget

## Описание:
Bank Widget - это проект, созданный и постепенно дорабатываемый в рамках обучения языку программирования Python.

## Цель проекта:
Главной целью Bank Widget является получение и совершенствование навыков по работе с локаоьным и удаленным репозиторием Git.

## Установка:
1. Запустите IDE на локальном ПК.


2. Клонируйте Bank Widget из удаленного репозитория.

    Для этого можно из текущей директории на вашем ПК можно ввести в терминале команду:git clone git@github.com:havaikrab/bank_widget.git


3. Установите зависимости.

    В проекте используется менеджер зависимостей Poetry, установите его, при необходимости.
    Для установки зависимостей введите в терминале команду: poetry install

## Инструкции и комментарии к функциям:

### get_mask_card_number()

Функция принимает на вход строку с номером карты и возвращает ее маску.  
Номер карты замаскирован и отображается в формате  
XXXX XX** **** XXXX,  
где X — это цифра номера.  

#### Пример работы функции:  

Входные данные: 7000792289606361  
Результат:      7000 79** **** 6361  

### get_mask_account()

Функция принимает на вход строку с номером счета и возвращает ее маску.  
Номер счета замаскирован и отображается в формате  
**XXXX  
где X — это цифра номера.  

#### Пример работы функции:  

Входные данные: 73654108430135874305  
Результат:      **4305

### mask_account_card()

Функция принимает один аргумент — строку, содержащую тип и номер карты или счета,
и возвращает строку с замаскированным номером.  
Для маскировки номеров карт и счетов используются соответствующие функции get_mask_card_number() и get_mask_account()  

#### Примеры работы функции:  

Входные данные: Visa Platinum 7000792289606361  
Результат:      Visa Platinum 7000 79** **** 6361  

Входные данные: Счет 73654108430135874305  
Результат:      Счет **4305

### get_date

Функция принимает на вход строку с датой в формате:  
"2024-03-11T02:26:18.671407"  
и возвращает строку с датой в формате "ДД.ММ.ГГГГ"  
"11.03.2024".

### filter_by_state()

Функция принимает список словарей и, опционально, значение для ключа state,  
по умолчанию state = 'EXECUTED'.  
Функция возвращает новый список словарей с соответствующим значением ключа state

### sort_by_date()

Функция принимает список словарей и опциональный параметр, задающий порядок сортировки,  
по умолчанию сортировка происходит по убыванию.  
Функция возвращает новый список, отсортированный по дате, то есть по значению ключа "date".

### filter_by_currency()

Функция-генератор принимает список словарей, каждый словарь содержит детальное описание банковских транзакций.  
Данная функция перебирает передаваемый список и
по одному возвращает словари, соответствующие транзакциям с кодом денежной единицы, передаваемой в виде строки вторым аргументом.

### transaction_descriptions()

Функция-генератор принимает список словарей, каждый словарь содержит детальное описание банковских транзакций.
Данная функция перебирает передаваемый список и по одному возвращает текстовый комментарий для каждой транзакции,
если таковой есть в соответствующем словаре.

### card_number_generator()

Функция-генератор номеров банковских карт.
Функция принимает два аргумента - начальное и конечное значение диапазона генерации номеров в формате натурального числа.
Функция имеет ограничения для обрабатываемого диапазона:
оба передаваемые аргумента должны быть больше, либо равны 1,
оба передаваемые аргумента должны быть меньше, либо равны 9999999999999999,
первый аргумент должен быть меньше, либо равен второму.
Функция по одной возвращает строки в формате "XXXX XXXX XXXX XXXX", где "X" - это цифра от 0 до 9,
для каждого числа в указанном диапазоне включительно.

#### Примеры работы функции:

Входные данные:  
35, 37  
Результат при вызове:  
"0000 0000 0000 0035"  
"0000 0000 0000 0036"  
"0000 0000 0000 0037"

### log()

Функция-декоратор, обеспечивающая логирование декорируемой ею функции.  
Данная функция имеет один опциональный параметр <filename>, который соответствует имени файла,
в который будет вноситься информация о вызове декорированных функций.  
По умолчанию, значерние параметра <filename> None, при этом значении информация о вызове функции выводится в консоль IDE.  
Логирование включает в себя следующую информацию:  
Имя вызываемой функции.  
Время вызова функции.  
Результат, в случае успешной работы функции.  
Информация об ошибке, в случае возникновения исключения.  
Входные данные, в случае возникновения исключения.  
Время завершения работы функции, в случае ее успешной работы.

### get_transactions()

Функция, которая в качестве аргумента принимает путь к файлу в виде строки.  
Данная функция предназначена для трансформации содержимого JSON-файла в список словарей,
содержащих информацию о финансовых транзакциях.

### get_currency_rate_by_date()

Функция, которая в качестве аргументов принимает код валюты и дату транзакции в виде строки.  
Данная функция обращается к внешнему ресурсу, хранящему информацию о ежедневных курсах многих валют.  
Результат работы функции - словарь, содержащий следующую информацию:  
1. Статус обращения к внешнему ресурсу и получнного ответа.
2. Курс валюты, код которой был передан функции, относительно Рубля в передаваемую дату.

### get_amount_rubles()

Функция, которая в качестве аргумента принимает словарь, содержащий информацию о банковской транзакции.
Данная функция возвращает сумму транзакции.
Если валюта транзакции - Рубль, то сумма транзакции возвращается без изменений.  
Если же валюта отличается от Рубля, то данная функция обращается посредством функции get_currency_rate_by_date()
к внешнему ресурсу для получения актуального курса данной валюты относительно рубля на дату транзакции.
После получения искомого курса get_amount_rubles() возвращает сумму транзакции в рублевом эквиваленте.

### csv_data_reader()

Функция, которая в качестве аргумента принимает строку, соответствующую пути к открываемому файлу с расширением csv.  
Ожидается, что открываемый файл является базой данных банковских транзакций.
Соответственно, функция проверяет наличие необходимых заголовков в файле и формирует список словарей-транзакций
в соответствии с форматом, который используется в проекте большинством других функций.

### xlsx_data_reader()

Функция, аналогичная функции csv_data_reader(), также принимает в качестве аргумента строку пути к файлу.
Результат работы функции - отформатированный список словарей-транзакций.
